## 2026-10-29 (2) · 로컬 Claude Code · `claude/play-fixes-fx`
- 뽑기: 이미 가진 ★★★와 최대 레벨인 것은 나오지 않는다. 나온 등급에 남은 것이 없으면 아래 등급 → 위 등급에서 고른다. 전부 최대(총 1,045레벨)면 별빛 결정으로 돌려준다(★★★ 50 · ★★ 15 · ★ 5). 금화 환급은 없앴다.
- 상점 결정 양 ×5 (가격 그대로, 상품 id 그대로): 500/1,650/5,750, 초보자 1,500, 광고 제거 덤 500, 축복 1,000 + 매일 300. 근거: 전부 최대까지 1,045회 × 결정 54(10회 540) ≈ 56,400 → 큰 묶음 기준 약 9.8만 원.
- 2배속(유료, 상품 `speed_mode` ₩3,000, 1회): `G.speedOn()`일 때 `game.time`과 스폰 디렉터만 2배(적 2배·보스 시각 당겨짐), 이동·공격은 그대로. 일시정지 화면 버튼으로 켜고 끄며, 안 샀으면 상점으로. HUD 시간 옆에 ×2. 그림 `assets/sprites/store_speed.svg`.
- 상자·뽑기 연출을 처음부터 새로: Codex `gpt-6-astra`가 디자인·구현, Claude가 검토·확인. 상자는 낙하 → 흔들림·빛 누출 → 등급 각성 → 개봉 → 카드, 문구가 단계마다 바뀌며 4.2~6초. 뽑기는 원형 대신 매달린 각진 등불과 빛의 장막, ★★★은 암전 뒤 금빛 기둥, 10회는 0.5초 간격으로 한 장씩.
- 안드로이드 포장 `android-app/`(Capacitor 8): 광고(AdMob)·결제(구글 플레이) 다리 `native-bridge.js`. 할 일과 상품 id 표는 `docs/android-release.md`.
- Codex를 백그라운드로 돌릴 때는 `< /dev/null`을 붙인다(안 붙이면 stdin을 기다리다 아무것도 안 하고 끝난다). 모델: `-m gpt-6-astra`.

## 2026-10-29 · 로컬 Claude Code · `claude/play-fixes-fx`
Codex가 읽기 전용으로 출시 전 코드 검토를 했고(아래 버그 목록의 출처), Claude가 확인 후 고쳤다.
- 저장 실패 시 "저장하고 나가기"가 나가지 않고 "저장 실패 · 다시 시도"를 보여 준다 (`G.storage.set`·`G.saveRun`이 성공 여부를 돌려준다).
- 쓰러지는 순간 정산을 먼저 저장한다(`game.deathSettle`). 예전에는 1.3초 연출 중 앱이 꺼지면 그 판 금화가 사라졌다.
- 느린 폰(20fps 미만)에서 게임 시간이 느려지던 문제: 한 프레임을 0.05초 이하로 나눠 진행(최대 0.1초).
- 판 저장 시 적 450마리로 자를 때 보스·엘리트를 먼저 남긴다(보스가 사라지던 문제).
- 투사체 충돌 순회 배열(`projNear`)을 범위 검색 배열(`near`)과 분리 — 화염 폭풍·뇌화살이 적을 건너뛰던 문제.
- 이어하기: 깨진 숫자·배열 없는 저장은 버리고, 없어진 패시브·조합 키는 건너뛰며, 복원 중 예외가 나면 저장을 지우고 타이틀로.
- 상자·뽑기 연출 강화: 새 `src/ui/celebrate.js`(`G.celebrate` — 빨려드는 빛, 폭발 불꽃, 충격파, 빛기둥, 별 색종이, 화면 흔들림). 3성·조합 카드에 무지개 테두리, 2성 카드에 보랏빛 흐름. 움직임 줄이기 설정이면 꺼진다.
- 아직 안 한 것: Codex 지적 중 "이어하기 후 덫·웅덩이·회오리 같은 설치물 상태가 사라짐"(저장에 없음), 터치·회전·성능은 실기기 필요.
