## 2026-10-29 · 로컬 Claude Code · `claude/play-fixes-fx`
Codex가 읽기 전용으로 출시 전 코드 검토를 했고(아래 버그 목록의 출처), Claude가 확인 후 고쳤다.
- 저장 실패 시 "저장하고 나가기"가 나가지 않고 "저장 실패 · 다시 시도"를 보여 준다 (`G.storage.set`·`G.saveRun`이 성공 여부를 돌려준다).
- 쓰러지는 순간 정산을 먼저 저장한다(`game.deathSettle`). 예전에는 1.3초 연출 중 앱이 꺼지면 그 판 금화가 사라졌다.
- 느린 폰(20fps 미만)에서 게임 시간이 느려지던 문제: 한 프레임을 0.05초 이하로 나눠 진행(최대 0.1초).
- 판 저장 시 적 450마리로 자를 때 보스·엘리트를 먼저 남긴다(보스가 사라지던 문제).
- 투사체 충돌 순회 배열(`projNear`)을 범위 검색 배열(`near`)과 분리 — 화염 폭풍·뇌화살이 적을 건너뛰던 문제.
- 이어하기: 깨진 숫자·배열 없는 저장은 버리고, 없어진 패시브·조합 키는 건너뛰며, 복원 중 예외가 나면 저장을 지우고 타이틀로.
- 상자·뽑기 연출 강화: 새 `src/ui/celebrate.js`(`G.celebrate` — 빨려드는 빛, 폭발 불꽃, 충격파, 빛기둥, 별 색종이, 화면 흔들림). 3성·조합 카드에 무지개 테두리, 2성 카드에 보랏빛 흐름. 움직임 줄이기 설정이면 꺼진다.
- 아직 안 한 것: Codex 지적 중 "이어하기 후 덫·웅덩이·회오리 같은 설치물 상태가 사라짐"(저장에 없음), 터치·회전·성능은 실기기 필요.
