# HOLLOWLIGHT — 아트 가이드

게임의 모든 그림은 이 문서를 따른다. 그림은 `assets/sprites/`의 SVG 파일이고, 게임은 이 파일을 불러와 캔버스에 그린다.
같은 파일이 Claude Design 아트 보드에도 그대로 쓰인다.

## 세계관
깊은 밤의 숲. 플레이어는 꺼지지 않는 등불을 든 **등불지기**(첫 번째 챔피언). 등불 빛이 닿는 곳만 안전하고, 어둠에서 이끼 슬라임·그림자 박쥐·바위 골렘이 몰려온다. 20분을 버티면 새벽이 온다.

## 화풍
- **벡터 일러스트, 도트(픽셀) 아님.** 부드러운 그라디언트 + 2~3단 셀 음영 + 림라이트.
- 빛은 두 개: 등불의 **따뜻한 호박색 빛**(아래·옆에서), 달의 **차가운 청록·보라 빛**(왼쪽 위에서). 어두운 면은 차가운 색, 밝은 면은 따뜻한 색.
- 실루엣이 먼저다. 화면이 작고 적이 수백 마리 겹치므로 덩어리가 크고 읽기 쉬운 형태로 그린다. 잔선과 작은 디테일은 줄인다.
- 외곽선: 어두운 청록 `#0a1110`, 128px 캔버스 기준 3~4px, 끝이 둥근 선. 어두운 배경에서도 형태가 읽히게 한다.
- 캐릭터 발밑 그림자는 그리지 않는다(게임이 그린다). 등불의 빛 번짐(글로우)도 게임이 그린다. 등불 몸체는 그린다.
- 참고하되 베끼지 않는 느낌: Hades의 굵은 형태감, Don't Starve의 숲 분위기, Ori의 빛 표현. 완전히 오리지널 디자인.

## SVG 기술 규칙
- 파일마다 `<svg xmlns="http://www.w3.org/2000/svg" viewBox="...">`. `width`/`height` 속성은 viewBox와 같은 값으로 넣는다.
- 외부 참조, `<image>`, `<text>`, 폰트, `<style>`, `<script>`, 애니메이션 금지. 모양·그라디언트·`<filter>`(blur 정도)만.
- `id`는 파일마다 고유하게 접두어를 붙인다(예: `slime0-body`). 여러 SVG가 한 페이지에 들어가도 안 겹치게.
- 투명 배경. 크기는 아래 표의 viewBox를 정확히 지킨다. 기준점(anchor)에 맞춰 배치한다.
- 애니메이션 프레임은 같은 캐릭터가 같은 위치·크기로 그려져야 한다(프레임 사이에 몸이 튀지 않게).
