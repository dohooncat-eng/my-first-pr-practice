# HOLLOWLIGHT

꺼지지 않는 등불 하나로 밤을 20분 동안 버티는 생존 액션 게임입니다(Vampire Survivors 같은 "뱀서류").
공격은 자동으로 나갑니다. 플레이어는 적을 피하고 경험치 결정을 모아 레벨을 올리고, 무기와 능력을 조합해 강해집니다.

## 실행 방법

설치할 것은 없습니다. `index.html`을 브라우저로 열면 바로 시작됩니다.

로컬 서버로 열고 싶다면:

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## 조작

| 동작 | 키보드 | 휴대폰 |
|---|---|---|
| 이동 | WASD 또는 방향키 | 화면을 누른 채 끌기 |
| 일시정지 | Esc 또는 P | 오른쪽 위 버튼 |
| 레벨업 선택 | 1~5 또는 클릭, R 다시 뽑기 | 카드 누르기 |

## 게임 내용

- **스테이지 4개**: 속삭이는 숲 → 가라앉은 늪 → 잿빛 폐허 → 달의 심연. 앞 스테이지를 깨면 다음이 열립니다. 한 판은 20:00 생존이 목표입니다.
- **난이도 3단계**: 보통 · 어려움(적 1.5배, 금화 1.8배) · MAX(적 2배, 체력 3배, 엘리트 30초마다, 금화 3배). 스테이지마다 보통을 깨면 어려움, 어려움을 깨면 MAX가 열립니다. 화면에 적이 최대 800마리까지 나옵니다.
- **적 흐름**: 처음 몇 분은 적이 적게 나오고, 5~12분에 빠르게 늘어나며 체력도 가파르게 오릅니다.
- **중간 보스**: 5:00 · 10:00 · 15:00에 스테이지 보스가 점점 강해지며 나옵니다. 공격 전에 바닥에 경고 표시가 뜹니다. 처치하면 **상자**를 떨어뜨립니다.
- **상자**: 엘리트와 보스가 떨어뜨립니다. 조합 조건이 맞으면 무조건 조합하고, 나머지는 확률로 1~5개(40 · 22 · 20 · 10 · 8%)를 강화합니다. 보스 상자는 최소 3개. 별의 가호가 많을수록 많이 나옵니다. 개수에 따라 나무 · 은 · 금 상자로 열리고, 3개는 보라 빛, 5개는 무지갯빛 연출이 나옵니다.
- **무기 14종**과 **패시브 15종**은 각각 Lv 5까지 오르고, 무기·패시브 칸은 각 6칸입니다. 처음엔 무기 6·패시브 6만 나오고, 늪·폐허·심연이 열릴 때마다 무기·패시브가 6·6·5개씩 더 나옵니다.
- **조합 20종**
  - 진화 14: 무기 Lv 5 + 짝이 되는 패시브
  - 무기 조합 3: 두 무기 모두 Lv 5
  - 패시브 조합 3: 두 패시브 모두 Lv 5
  - 일시정지 메뉴의 조합 도감에서 조건을 볼 수 있습니다.
- **챔피언 4명**: 등불지기, 은빛 기사, 반딧불 마녀, 그림자 사냥꾼. 시작 무기와 특성이 다릅니다.
- **업그레이드**: 판마다 얻는 금화로 챔피언을 해금하고, 챔피언 고유 능력을 Lv 5까지 강화합니다. Lv 5에서는 각성 효과가 붙습니다.
- **뽑기(가챠)**: 금화나 별빛 결정으로 모든 챔피언에게 적용되는 영구 강화를 뽑습니다. 23종
  - ★★★ 5종(한 번만 뽑으면 끝): 레벨업 카드 +1장, 판마다 다시 뽑기 3회, 판마다 부활 1회, 투사체 +1, 상자 강화 +1
  - ★★ 8종(Lv 5까지), ★ 10종(Lv 100까지)
  - 확률 ★★★ 1.5% · ★★ 15% · ★ 83.5%, 10회 뽑기는 ★★ 이상 보장, 100번째에 ★★★ 확정(천장). 뽑기 화면의 "확률 정보"에서 종류별 확률을 볼 수 있습니다.
  - 별빛 결정은 스테이지·난이도를 처음 깰 때(30 · 60 · 100)와 상점에서 얻습니다.
- **상점**: 별빛 결정 묶음(₩1,000 · ₩3,000 · ₩10,000, 첫 구매 2배), 초보자 패키지(₩2,000), 광고 제거(₩3,000), 등불 축복 30일(₩4,000), 결정 → 금화 교환. 웹에서는 결제가 되지 않고 안내만 나옵니다(구글 플레이 앱에서 연결 예정).
- **소리**: 스테이지마다 다른 배경 음악(보스가 나오면 긴장 레이어가 붙음)과 효과음 29종. 모두 코드로 합성해서 음원 파일이 없습니다.
- **설정**: 효과음·배경 음악 크기, 화면 흔들림, 데미지 숫자, FPS 표시, 그래픽 품질(자동 · 높음 · 보통 · 낮음, 자동은 느려지면 해상도를 낮춤), 쿠폰 코드, 전체 화면, 저장 데이터 초기화
- **재화 한도**: 금화 9,999,999 · 별빛 결정 99,999
- **이어하기**: 플레이 중 10초마다, 그리고 창을 닫거나 탭을 옮길 때 자동 저장합니다. 다음에 열면 타이틀에서 이어할 수 있습니다.

## 폴더 구조

코드 구조와 파일별 역할은 [docs/architecture.md](docs/architecture.md), 그림 규칙과 전체 스프라이트 목록은 [docs/art-style.md](docs/art-style.md)에 있습니다.

```
index.html, style.css   화면 뼈대와 스타일
src/data/               무기·패시브·조합·챔피언·스테이지·적·가챠·상점 수치
src/systems/            무기 동작, 조합, 상자, 보스, 저장, 메타 진행, 가챠, 결제·광고, 효과음
src/ui/                 HUD와 메뉴 화면
src/*.js                게임 루프, 플레이어, 적, 스폰, 줍기, 효과
assets/sprites/         게임 그림 (SVG)
```

## 개발용 옵션

주소 끝에 `?debug`를 붙이면 경험치를 5배로 얻고, 플레이 중 아래 키를 쓸 수 있습니다.

- `L` 레벨업 · `K` 60초 건너뛰기 · `H` 체력 회복
- `B` 보스 부르기 · `C` 상자 · `V` 보스 상자 떨어뜨리기 · `M` 가진 무기·패시브 모두 Lv 5 · `G` 금화 1000
- 상점 구매와 광고 보상이 시험용으로 바로 지급됩니다.
