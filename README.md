# 서울 기후 100년

서울(관측소 108)의 1904–2025년 연평균 기온을 조회하고 그래프로 보는 웹앱입니다.

- `index.html`을 브라우저로 열면 바로 실행됩니다 (서버 불필요).
- 연도를 입력하면 연평균·평균 최저·평균 최고 기온, 1908–1937 평균 대비 차이, 순위를 보여 줍니다.
- 그래프는 연평균 기온과 10년 이동평균을 그리며, 기간을 지정해 확대할 수 있습니다.

## 자료

- `data/seoul_daily_temperature.csv`: 기상청 기상자료개방포털 서울 일별 기온 (UTF-8로 변환)
- `data.js`: `python3 scripts/build_annual.py`로 생성한 연도별 평균값
- 관측일이 330일 미만인 해(1904–1907, 1950–1953)는 자료 없음으로 표시합니다.

# 통합과학 가상 실험실 (`science-lab/`)

2022 개정 통합과학 1·2 내용을 다루는 탐구 시뮬레이션 12가지입니다. `science-lab/index.html`을 브라우저로 열면 실행됩니다.

| 영역 | 실험 |
| --- | --- |
| 화학 | 산·염기 중화 반응 (이온 모형, pH·온도·전기 전도도), 산화·환원 반응, 원소와 화학 결합 |
| 물리 | 자유 낙하와 수평으로 던진 물체, 운동량과 충격량, 전자기 유도와 발전기 |
| 지구·우주 | 스펙트럼과 우주의 원소, 지질 시대와 생물 대멸종, 방사성 붕괴와 절대 연령, 온실 효과와 지구 에너지 균형 |
| 생명 | 세포막과 삼투, 효소와 활성화 에너지 |

- `js/core.js`: 그래프, 조작 장치, 캔버스 등 공통 도구
- `js/m-*.js`: 실험 모듈 (각 파일 끝에 이론 노트와 자료 출처)
- 온실 효과 실험은 루트의 `data.js`(서울 연평균 기온)를 함께 불러옵니다.
