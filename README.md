# 등불지기

꺼지지 않는 등불 하나로 밤의 숲을 10분 동안 버티는 생존 액션 게임입니다.
공격은 자동으로 나가고, 플레이어는 움직이며 적을 피하고 경험치 결정을 모아 강해집니다.
(Vampire Survivors 같은 "뱀서류" 장르)

## 실행 방법

설치할 것은 없습니다. `index.html`을 브라우저로 열면 바로 시작됩니다.

로컬 서버로 열고 싶다면:

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 엽니다.

## 조작

| 동작 | 키보드 | 휴대폰 |
|---|---|---|
| 이동 | WASD 또는 방향키 | 화면을 누른 채 끌기 |
| 일시정지 | Esc 또는 P | 오른쪽 위 버튼 |
| 레벨업 선택 | 1 · 2 · 3 또는 클릭 | 카드 누르기 |

## 게임 내용

- **무기 4종** (각 최대 Lv 5): 불씨 화살, 은빛 검, 반딧불, 등불 오라
- **패시브 5종** (각 최대 Lv 5): 튼튼한 몸, 가벼운 발, 불꽃 심지, 숙련, 끌림
- **적 3종**: 이끼 슬라임, 그림자 박쥐(떼로 몰려옴), 바위 골렘. 1분마다 강한 엘리트가 나옵니다.
- **줍는 것**: 경험치 결정(파랑·청록·보라), 약초(체력 회복), 끌림의 부적(화면의 모든 결정을 끌어옴)
- 10:00을 버티면 클리어. 최고 기록은 브라우저에 저장됩니다.

## 폴더 구조

```
index.html          화면 뼈대 (캔버스 + 타이틀·레벨업·일시정지·결과 화면)
style.css           HTML 화면 스타일
src/
  utils.js          수학, 랜덤, 충돌용 공간 분할 그리드, 저장소
  input.js          키보드와 터치 조이스틱
  sprites.js        SVG 그림을 불러와 미리 래스터화
  effects.js        데미지 숫자, 파티클, 화면 흔들림, 알림
  player.js         플레이어 이동·체력·경험치
  enemies.js        적 종류, 추적 이동, 처치
  weapons.js        무기 4종과 투사체
  upgrades.js       패시브와 레벨업 선택지
  spawner.js        시간별 적 등장
  pickups.js        결정과 아이템
  ui.js             HUD와 HTML 화면 제어
  game.js           상태 머신, 메인 루프, 빛과 어둠 그리기
  main.js           시작점
assets/sprites/     게임 그림 (SVG)
docs/art-style.md   아트 가이드: 화풍, 팔레트, 스프라이트 목록과 크기
```

## 개발용 옵션

주소 끝에 `?debug`를 붙이면 경험치를 5배로 얻고, 아래 키를 쓸 수 있습니다.

- `L`: 바로 레벨업
- `K`: 시간 60초 건너뛰기
- `H`: 체력 가득 채우기
