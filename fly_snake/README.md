# 초파리 뇌가 하는 스네이크

FlyWire 초파리 커넥톰(v783, 뉴런 138,639개 · 연결 1,500만 개)으로 만든 뇌 전체 LIF 모델이 스네이크를 합니다.
뉴런 모델과 파라미터는 Shiu et al. 2024 (Nature)와 같고, `brain.py`에서 numpy로 다시 구현했습니다.

![demo](results/snake_seed1.gif)

## 동작 방식
- 먹이가 왼쪽/오른쪽에 보이면 그쪽 눈의 **LC10**(작은 물체 감지) 시각뉴런을 Poisson 자극합니다.
- 장애물이 바로 옆/앞에 있으면 **LC4 · LPLC2**(다가오는 물체 감지) 뉴런을 자극합니다.
- 뇌를 200 ms 시뮬레이션한 뒤 조향 하강뉴런 **DNa01 + DNa02** 중 더 많이 발화한 쪽으로 꺾습니다.
- 게임 코드는 먹이 위치로 방향을 정하지 않습니다. "LC10은 같은 쪽으로 돌고, LC4/LPLC2는 반대쪽으로 돈다"는 관계는 커넥톰에서 나온 결과입니다.

## 집 컴퓨터에서 실행하기

### 1. 브라우저로 보기 (설치 필요 없음)
1. 저장소를 받습니다. GitHub에서 `claude/compassionate-meitner-9z6yrf` 브랜치를 고른 뒤 **Code → Download ZIP**,
   또는 `git clone -b claude/compassionate-meitner-9z6yrf https://github.com/dohooncat-eng/my-first-pr-practice`
2. `fly_snake/web/fly_snake.html`을 Chrome이나 Edge로 엽니다(더블클릭). 인터넷 연결이 없어도 돌아갑니다.
3. **그룹당 초파리 수**를 고르고(예: 33 → 99마리), **계산에 쓸 CPU 스레드**를 고른 뒤 **실험 시작**.
   스레드 기본값은 "코어 수 − 1"입니다. 8코어 16스레드 CPU라면 15개가 기본입니다.

한 스레드가 1초에 약 4~5수를 계산합니다. 스레드 15개면 전체 약 60~75수/초이고, 99마리면 한 마리당 약 0.7수/초입니다.
메모리는 99마리에 1GB 안팎을 씁니다.

### 2. 통계만 빠르게 (Node.js 18 이상)
화면 없이 여러 판을 병렬로 돌려 그룹별 평균과 학습 곡선을 출력합니다.
```bash
cd fly_snake
node tools/batch.js 32 100 16          # 시드 32개 × 3그룹 × 100판, 스레드 16개
node tools/batch.js 16 60 16 off,rpe RPE_LR=0.3 TEMP=8   # 그룹과 학습 값 바꿔 보기
```
결과는 `tools/batch_results.json`에도 저장됩니다.

### 3. 배운 뇌를 저장하고 이어서 학습하기
학습한 시냅스는 저장해 두었다가 다음 실행에서 이어서 학습할 수 있습니다.
```bash
node tools/batch.js 16 200 16 rpe --save=brains            # 16마리 × 200판 학습, brains/rpe_seed1.json … 저장
node tools/batch.js 16 200 16 rpe --load=brains/rpe_seed3.json --save=brains2   # 가장 잘한 뇌에서 다시 출발
```
각 파일의 `recentMean`이 마지막 20판 평균 먹이입니다. 브라우저 화면의 **파일에서 불러오기**로 같은 파일을 열면
학습 그룹이 그 뇌에서 출발하는 모습을 볼 수 있습니다. 화면의 **가장 잘 배운 뇌 저장**은 브라우저 안에 저장합니다.

## 브라우저 실험 화면 (`web/fly_snake.html`)
전체 뇌로 게임을 돌리며 한 번이라도 발화한 뉴런 14,055개와 그 사이 연결 143만 쌍을 브라우저로 옮겼습니다.
발화하지 않는 뉴런은 다른 뉴런에 영향을 주지 않으므로 이 부분 회로는 게임 중 전체 뇌와 같은 계산을 합니다
(`tools/test_web.js`로 확인: LC10 왼쪽 자극 → 조향 L 277 Hz, 전체 뇌 267 Hz).

세 그룹을 같은 먹이 순서로 동시에 돌립니다.
- **본능**: 시냅스 고정.
- **학습 A (헤비안)**: 조향 뉴런(DNa01/02)으로 들어오는 흥분성 시냅스 680개를 "전·후 뉴런 동시 발화 × 보상"만큼 바꿉니다.
- **학습 B (보상 예측 오차)**: 같은 시냅스를 "(보상 − 최근 평균 보상) × 전 뉴런 발화 × (고른 쪽 − 고를 확률)"만큼 바꿉니다. 꺾을 확률은 조향 뉴런 출력에서 정하므로 가끔 다른 쪽도 시도합니다.

보상: 먹이 +1, 가까워짐 +0.1, 멀어짐 −0.1, 충돌 −1. 둘 다 도파민 학습을 단순화한 것이며, 실제 초파리에서 이 시냅스가 이렇게 바뀐다는 근거는 없습니다.

### 왜 죽나
`node tools/crash_causes.js 30 5` (본능 30판): 23판은 먹이 쪽으로 꺾다가 그쪽 벽·몸통에 부딪혔고, 7판은 정면 벽을 양쪽 눈이 똑같이 봐서 직진했습니다.
먹이 신호(LC10)가 위험 신호(LC4·LPLC2)를 이기는 것이 주 원인입니다. 전체 뇌(13만 8천 뉴런)로 돌렸을 때도 12~23수 만에 죽었으므로 뉴런 수 문제는 아닙니다.

| 학습 B (보상 예측 오차) | RPE_LR 0.03, TEMP 15 | 4 | 40 | 2.96 | |
| 학습 B | RPE_LR 0.15, TEMP 15 | 4 | 40 | 3.13 | |

학습 A가 가장 좋지만, 바뀐 내용은 조향 시냅스 전체가 약 2.8배 세진 것(먹이 쪽으로 더 확실하게 꺾음)에 가깝습니다.

배울 수 있는 곳이 조향 뉴런 4개로 들어오는 시냅스 680개뿐이고, 눈이 바로 옆 칸만 보기 때문에 오를 수 있는 한계가 낮은 것으로 보입니다.
